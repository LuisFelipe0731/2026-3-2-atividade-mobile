## Desenvolvimento

### Frontend mobile/web

```bash
cd web
npm install
npm run web
```

Para abrir no celular com o Expo Go, execute `npx expo start` dentro de `web` e escaneie o QR code.

### API

```bash
cd api
npm install
npm run dev
```

Verifique o servidor em `http://localhost:3001/api/health`.
